# PRD: Qazaqsha — приложение для изучения казахского языка

**Статус:** реализовано (живой прототип, опубликован как Claude Artifact)
**Формат:** self-contained веб-приложение (один HTML-файл)
**Ссылка на прод:** https://claude.ai/artifact/M5WvBxABK4K14YeUM3Uq74

---

## 1. Обзор

Qazaqsha — веб-приложение для изучения казахского языка в формате Duolingo: короткие интерактивные уроки, geймификация (сердца, очки опыта, серия дней), несколько уровней сложности и упражнения на все основные языковые навыки — словарный запас, письмо, аудирование, грамматику и говорение.

Интерфейс приложения — на русском языке (целевая аудитория — русскоязычные пользователи, изучающие казахский с нуля или продолжающие обучение).

## 2. Цели

- Дать пользователю возможность учить казахский язык самостоятельно, в собственном темпе, без привязки к учебнику.
- Позволить выбрать стартовый уровень самому (а не проходить всё строго по порядку) — как новичкам, так и продолжающим.
- Охватить все заявленные аспекты владения языком: словарный запас, говорение, письмо, грамматику, понимание речи на слух.
- Дать пользователю понятную обратную связь о его реальном уровне владения языком (не только «пройдено/не пройдено», а оценку по навыкам).
- Сделать процесс вовлекающим за счёт игровых механик и дружелюбного визуального персонажа.

## 3. Целевая аудитория

Русскоязычные пользователи (в первую очередь в Казахстане), желающие изучать казахский язык — от полного нуля (A1) до продолжающих с базовыми знаниями, которые хотят закрыть пробелы в грамматике и разговорной практике (до B2).

## 4. Объём на текущий момент

| Показатель | Значение |
|---|---|
| Уровней | 4 (A1, A2, B1, B2) |
| Уроков на уровень | 10 |
| Уроков всего | 40 |
| Заданий в уроке | 7 |
| Заданий всего | ~280 |
| Навыков, охваченных заданиями | 5 (словарь, письмо, аудирование, грамматика, говорение) |

## 5. Функциональные требования

### 5.1 Уровни и структура обучения

- Четыре уровня, выбираемые пользователем свободно (без обязательной последовательной разблокировки) — соответствуют условным CEFR-подобным ступеням:
  - **A1 — Негізгі деңгей** (Начальный)
  - **A2 — Бастапқы деңгей** (Элементарный)
  - **B1 — Орта деңгей** (Средний)
  - **B2 — Жоғары деңгей** (Продвинутый)
- Каждый уровень отображается на главном экране как узел на «тропе» (path UI), с цветовым кодом и прогресс-баром выполнения.
- Внутри уровня — список уроков (юнитов) с иконкой, названием на казахском и русским переводом, количеством заданий и отметкой о прохождении.

### 5.2 Типы упражнений

В каждом уроке — 7 заданий, комбинация из 5 типов:

| Тип | Навык | Формат |
|---|---|---|
| `choice` | словарный запас / грамматика | выбор верного перевода из 4 вариантов |
| `translate` | письмо | ввод слова/фразы на казахском текстом |
| `listen` | аудирование | прослушать фразу (TTS) и выбрать верный перевод |
| `fill` | грамматика | заполнить пропуск в предложении, выбрав из вариантов |
| `speak` | говорение | повторить фразу вслух, распознавание речи оценивает произношение |

### 5.3 Геймификация и прогресс

- **Сердца**: 5 жизней на сессию урока, −1 за каждый неверный ответ; при 0 сердец — урок прерывается, XP за пройденные задания всё равно засчитывается.
- **XP (очки опыта)**: +10 за каждый верный ответ, +20 бонус за первое прохождение урока.
- **Серия дней (streak)**: считает подряд идущие дни активности.
- Прогресс (пройденные уроки, XP, серия, статистика по навыкам) хранится в `localStorage` браузера — привязан к конкретному устройству/браузеру, не синхронизируется между устройствами.

### 5.4 Оценка прогресса («Прогресс»)

Отдельный экран с самостоятельной аналитикой владения языком:

- Общий процент владения языком (кольцевая диаграмма) — среднее по всем навыкам, по которым есть данные.
- Полосы прогресса по каждому из 5 навыков (словарный запас, письмо, аудирование, грамматика, говорение), рассчитываемые как доля верных ответов заданий этого типа.
- Для говорения — отдельная метрика точности произношения (см. 5.5).
- Пояснение методологии оценки прямо на экране.

### 5.5 Разговорная практика и оценка произношения

- В заданиях `speak` пользователь видит целевую фразу на казахском и её перевод, может прослушать эталонное произношение (TTS) и записать свой голос через Web Speech API (распознавание речи).
- Точность произношения считается через расстояние Левенштейна между распознанным текстом и эталонной фразой → процент схожести (0–100%).
- Ответ засчитывается как «верный» для статистики при точности ≥65%; в любом случае процент показывается пользователю и усредняется в общей статистике по говорению.
- Если распознавание речи недоступно в браузере — приложение сообщает об этом и позволяет просто потренироваться вслух без блокировки прогресса.

### 5.6 Рейтинг

- Экран с общим списком пользователей, отсортированным по XP.
- У каждого пользователя — редактируемое отображаемое имя и анонимный идентификатор устройства (генерируется локально, хранится в `localStorage`).
- Реализовано через встроенную в Claude Artifacts возможность `db` (общее хранилище для артефакта).
- **Важное ограничение**: рейтинг общий только для тех, кто открывает ссылку в рамках одной организации/аккаунта Claude — это не публичный интернет-рейтинг. Ограничение платформенное, не отключается.

### 5.7 Анимированный персонаж (в заданиях на аудирование)

- Дружелюбный иллюстрированный человеческий персонаж-наставник (SVG, с градиентной «объёмной» отрисовкой: кожа, волосы, одежда; шея, уши, брови, нос; золотая повязка на голове как культурная деталь).
- Появляется только в заданиях типа `listen` (понимание казахской речи на слух).
- Состояния и анимации:
  - **Покой** — плавное покачивание.
  - **Говорит** (во время воспроизведения аудио) — рот открывается/закрывается, руки жестикулируют, рядом анимированные «волны звука».
  - **Правильный ответ** — весёлая анимация (подпрыгивание), прищуренные глаза, случайная одобрительная реплика в облачке («Жарайсың!», «Керемет!» и т.д.).
  - **Неправильный ответ** — расстроенная поза, грустные брови, поддерживающая фраза («Ештеңе етпейді!», «Келесіде шығады!»).

### 5.8 Озвучивание (TTS) и качество произношения

- Озвучка реализована через браузерный Web Speech API (`speechSynthesis`), без внешних сервисов.
- Приоритет выбора голоса: **родной казахский голос** (если есть в системе) → **турецкий/азербайджанский** (близкие тюркские языки, фонетически ближе всего к казахскому среди распространённых голосов) → **русский** (как последний резерв) → голос по умолчанию.
- Для турецкого/азербайджанского голоса текст перед озвучкой транслитерируется в латиницу турецкого типа (ө→ö, ү→ü, ы→ı, қ/ғ→k/ğ и т.д.), поскольку эти движки не читают кириллицу — так казахские гласные и специфические буквы звучат значительно точнее.
- Для русского голоса (когда более близкого нет) специфические казахские буквы (ә, ғ, қ, ң, ө, ұ, ү, һ, і) заменяются на ближайшие русские перед озвучкой, чтобы слово читалось полностью и разборчиво, а не обрывалось на незнакомом символе.
- Известное ограничение: без установленного в системе настоящего казахского голоса TTS даёт лишь приближённое произношение, не уровень носителя языка.

## 7. Дизайн-система

- **Идея**: стилистика казахской степи и флага — не шаблонный «зелёный Duolingo».
- **Цвета**: небесно-голубой (`#1CA7C4`) и глубокий синий как основной акцент, золотой (`#EFA90C`) как акцент XP/успеха; у каждого уровня — свой опознавательный цвет (A1 голубой, A2 зелёный, B1 янтарный, B2 бордовый).
- **Типографика**: PT Serif (заголовки) + Golos Text (интерфейс) — шрифты с полной поддержкой казахской кириллицы (ә, ғ, қ, ң, ө, ұ, ү, һ, і).
- **Декоративные элементы**: орнаментальные мотивы (круги, лепестки) в шапке главного экрана; уровни выстроены как «тропа» с узлами вместо шаблонных карточек.
- Адаптивно для мобильных и десктопных экранов, с поддержкой светлой/тёмной темы.

## 8. Техническая архитектура

- Один самодостаточный HTML-файл (HTML/CSS/vanilla JS), опубликован через Claude Artifact.
- **Хранение личного прогресса**: `localStorage` (ключ `qazaqApp_v1`) — XP, серия, пройденные уроки, статистика по навыкам, анонимный ID устройства, отображаемое имя.
- **Общий рейтинг**: капабилити `db` (документное хранилище артефакта), коллекция `leaderboard`, документ на каждого пользователя (ключ — анонимный clientId), сортировка по XP, живое обновление через `onSnapshot`.
- **Озвучивание**: `window.speechSynthesis` с приоритетной цепочкой голосов и транслитерацией под выбранный голос (см. 5.8).
- **Распознавание речи**: `SpeechRecognition`/`webkitSpeechRecognition`, оценка через расстояние Левенштейна.
- Без сборки/фреймворков — весь UI рендерится через шаблонные строки и `innerHTML`.

## 9. Известные ограничения

- Прогресс не синхронизируется между устройствами/браузерами (только `localStorage`).
- Рейтинг общий только в рамках одной организации/аккаунта Claude — не публичный интернет-рейтинг (платформенное ограничение, не обходится).
- Озвучивание — это браузерный TTS, а не запись носителя языка; качество зависит от голосов, установленных в системе пользователя.
- Распознавание речи (оценка говорения) зависит от поддержки Web Speech API в браузере — не работает во всех браузерах одинаково (лучше всего — в Chrome).
- 40 уроков — это не финальный охват языка, а первая содержательная итерация; дальнейшее расширение контента возможно по запросу.

## 10. История изменений (в рамках этого проекта)

| Версия | Изменения |

## 11. Возможные следующие шаги (не реализовано)

- Дальнейшее расширение контента (больше уроков на уровень).
- Диагностический тест для автоматического определения стартового уровня.
- Синхронизация прогресса между устройствами (потребует полноценной идентификации пользователя).
- Более широкая публичность рейтинга (потребует архитектуры за пределами текущей платформы Claude Artifacts).
